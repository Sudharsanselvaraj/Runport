# Offline Dify Workflow Example

Demonstrates configuring and executing Runport's `DifyConnector` against a mock local HTTP endpoint.

---

## Files
- `run.py`: Spawns a lightweight local mock server and executes a Dify workflow request.

---

## How to Run

```bash
uv run python examples/dify-workflow/run.py
```

Runs completely offline in `<0.2s`.
